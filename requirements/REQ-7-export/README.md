# REQ-7：导出关系图

| 字段 | 值 |
| --- | --- |
| 状态 | `Planned` |
| 优先级 | `P2` |
| 目标版本 | `TBD` |
| 子需求 | 无 |

## 目标

用户能够把当前关系图保存为文件，首个版本支持纯文本格式，并避免意外覆盖已有数据。

## 需求

Canvas 模式输入 `w` 后打开保存弹窗，要求用户输入目标文件。目标不存在时写入；目标已经存在时拒绝覆盖并显示原因。

## 验收条件

- `w` 打开保存弹窗，而不是立即写入默认路径。
- 空路径、无效路径和写入失败显示错误，TUI 保持可用。
- 已存在的目标绝不被覆盖或截断。
- 文本输出对相同图状态保持稳定，明确表示 call/type、共享节点、循环和关系方向。
- 保存成功后显示目标路径。

## 当前实现与差距

尚无保存弹窗、序列化格式或文件写入实现。该父需求规模足够小，暂不拆分子需求；将来增加 JSON、Graphviz 等独立格式时再新增子需求。
