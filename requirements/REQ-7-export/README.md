# REQ-7：导出关系图

| 字段 | 值 |
| --- | --- |
| 状态 | `Implemented` |
| 优先级 | `P2` |
| 目标版本 | `0.1` |
| 子需求 | 无 |

## 目标

用户能够把当前关系图保存为文件，首个版本支持纯文本格式，并避免意外覆盖已有数据。

## 需求

Canvas 模式输入 `w` 后打开保存弹窗，要求用户输入目标文件。目标不存在时写入；目标已经存在时拒绝覆盖并显示原因。相对路径按 cgraph 进程的当前工作目录解析。

导出范围是从当前 anchors 可达的全部已知关系，包括已经加载但当前收起的分支；不导出因取消 anchor 或清除分支而不可达的孤立存储节点。首版格式以节点表和关系表表达图，不复制共享节点，也不把当前 viewport 裁剪状态写入文件。

## 验收条件

- `w` 打开保存弹窗，而不是立即写入默认路径。
- 空路径、无效路径和写入失败显示错误，TUI 保持可用。
- 已存在的目标绝不被覆盖或截断。
- 文本输出对相同图状态保持稳定，明确表示 call/type、共享节点、循环和关系方向。
- 保存成功后显示目标路径。

## 文本示例

```text
cgraph graph · text v1

Nodes (2)
  [1] call  main  [anchor]
      file:///project/src/main.rs:1:1
  [2] call  run
      location unknown

Relations (1)
  [1] main  →  [2] run
```

格式避免 `kind=...`、JSON 和 `null` 等机器语法噪音。共享节点在 `Nodes` 中只出现一次，关系通过局部编号引用；循环和自环用指回已有编号的箭头表达。

## 实现与验证

- `src/export/mod.rs` 负责稳定排序、简洁文本序列化和 `create_new` 安全写入。
- `src/app/save.rs` 保存与终端无关的弹窗状态；`src/tui/save.rs` 负责输入、错误显示和成功提示。
- 单元测试覆盖稳定输出、共享节点与循环、空路径、已有文件不被截断、成功/失败弹窗状态、`w` 入口，以及收起缓存与已清除孤立节点的导出边界。

该父需求规模足够小，暂不拆分子需求；将来增加 JSON、Graphviz 等独立格式时再新增子需求。
