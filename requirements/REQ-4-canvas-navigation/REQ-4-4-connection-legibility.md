# REQ-4-4：连线可读性

| 字段 | 值 |
| --- | --- |
| 父需求 | `REQ-4` |
| 状态 | `Implemented` |
| 优先级 | `P1` |
| 目标版本 | `0.1` |

## 目标

用户在普通等宽终端字体中也能辨认边的走向、转弯、目标和交叉关系；安装 Nerd Font 可以改善个人字体体验，但不能成为正确显示图结构的前提。

## 需求

- 默认字形只使用标准 Unicode box-drawing 和箭头字符，不依赖私用区图标。
- 单条正交边的转弯使用方向正确的拐角字符，不能把普通拐角误画为交叉点。
- 普通前向边在目标前显示方向箭头；反向/循环边继续使用双线、反向箭头或自环符号。
- 不同边真正横纵相交时，交叉单元同时使用明确字符和高亮样式，不能只依赖颜色。
- 单线与双线相交时保留双线所在轴向，使用户能够沿特殊边继续追踪。
- 节点覆盖连线端点，但不得清除节点之间或节点裁剪区域之外仍可见的有效线段。
- 连线可见性由完整路径与 viewport 的交集决定，不能因为任一端点方框完全离屏就丢弃仍在屏内的线段。

## 验收条件

- 普通边使用 `─`、`│` 和 `╭╮╰╯` 等标准单线字符，目标前可见 `▶`。
- 一条边自身的拐角不显示 `┼`，也不应用交叉高亮。
- 两条普通边横纵相交显示 `┼`；单线垂直穿过双线水平显示 `╪`，单线水平穿过双线垂直显示 `╫`。
- 真实交叉点使用与普通线段不同的强调样式；关闭彩色显示后仍可通过字符辨认。
- 常见等宽字体缺少 Nerd Font 扩展时，节点框和连线仍有完整语义。
- 目标方框在规范方向上刚刚离屏时，边界处仍保留指向该目标的箭头；远距离路径裁剪不按屏外距离逐 cell 枚举。

## 当前实现与差距

`canvas.rs` 先为每条 polyline 累积上下左右方向，再一次性映射为拐角、T 型或交叉字形。渲染阶段按坐标聚合不同边：同一边的方向合并只形成拐角，不触发交叉高亮；不同 edge identity 的横纵方向相遇才使用加粗洋红交叉点。普通边使用单线和 `▶`，循环/反向边使用黄色双线与 `◀`，自环使用 `↺`。路由端点来自所有世界节点的有符号投影；水平/垂直 segment 在遍历前裁剪到 viewport，因此端点离屏不会丢边，计算量也只与可见宽高相关。

未来可以增加可配置的 glyph/theme profile，但默认 profile 必须继续只依赖标准 Unicode；字体私用区图标不得承载唯一的结构语义。

## 实现证据

- `src/tui/canvas.rs` 实现方向掩码、单/双线字形选择、混合交叉点和按 edge identity 判定的交叉高亮。
- `src/tui/canvas/connections.rs` 单元测试覆盖普通拐角、普通交叉和 `╪` / `╫` 混合交叉。
- `src/tui/mod.rs` 渲染测试覆盖前向目标箭头，以及节点先后绘制时连接线仍存在。
