# REQ-4-3：有向图布局与反向边

| 字段 | 值 |
| --- | --- |
| 父需求 | `REQ-4` |
| 状态 | `Implemented` |
| 优先级 | `P1` |
| 目标版本 | `0.1` |

## 目标

画布把当前已展开关系表示为确定性的有向图布局。通常 caller/parent 位于节点左侧，callee/child 位于右侧；循环、自环或其他无法遵守左右顺序的边使用特殊线条符号显示。

## 需求

- call 规范边从 caller 指向 callee，type 规范边从 parent/supertype 指向 child/subtype。
- 从所有 anchor 出发，只沿当前已展开分支生成可见子图；缓存中存在但不可达的节点不渲染。
- 对可见图计算强连通分量，将收缩后的 DAG 按规范边方向从左到右分层。
- 同一个强连通分量内的边、自环和布局后目标未位于源右侧的边标记为反向/循环边。
- 普通边使用单线字符；反向/循环边使用双线字符和目标箭头，颜色只能作为补充信息。
- 布局、边路由、鼠标命中和键盘导航使用同一个不可变布局快照。

## 验收条件

- 菱形图的共享节点只有一个矩形，且所有可见关系都有连线。
- `A -> B -> C -> A` 和自环布局能够终止，不发生递归溢出。
- 非循环 DAG 中所有边满足源节点位于目标节点左侧。
- 循环/反向边不使用与普通边完全相同的字符族，并能看出语义目标。
- 不同 Unicode 显示宽度的节点矩形不重叠。
- 相同图状态产生稳定布局；展开局部关系时尽量保持已有节点的相对顺序。
- 多个不连通组件不会互相覆盖，当前选择所在组件靠近世界原点。

## 当前实现与差距

`canvas.rs` 从 RelationGraph 生成一次不可变世界/屏幕布局快照，对可见图运行 SCC 和收缩 DAG rank。普通边使用单线，SCC 内部边与自环使用黄色双线及目标符号；节点、连线、命中和导航共享快照。布局测试覆盖菱形、循环、自环、动态宽度碰撞和确定性世界布局。
