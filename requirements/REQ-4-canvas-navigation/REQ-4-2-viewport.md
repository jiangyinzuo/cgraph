# REQ-4-2：无限画布和平移

| 字段 | 值 |
| --- | --- |
| 父需求 | `REQ-4` |
| 状态 | `Implemented` |
| 优先级 | `P1` |
| 目标版本 | `0.1` |

## 需求

画布在逻辑上不受终端尺寸限制，节点使用世界坐标布局。用户可以拖拽背景或节点主体平移整体 viewport，以查看屏幕外节点；拖拽节点不表示单独重排该节点。

## 验收条件

- 平移只改变 viewport，不修改图结构或节点语义身份。
- 节点主体和画布空白区域都能发起平移；toggle 按钮不会误触发拖拽。
- 节点、连线和鼠标命中使用同一坐标变换。
- terminal resize 后重新裁剪显示，不丢失世界坐标。
- 多个图组件和 anchor 可以处于同一世界画布中。

## 当前实现

App 保存有符号 viewport 偏移，拖拽事件按连续鼠标位置的增量做饱和平移。TUI 先为所有展开节点生成不依赖终端大小的世界布局，再以画布中心和 viewport 偏移投影；只有完整进入可见区域的节点框参与本帧渲染、连线、命中和空间导航。terminal resize 只重新投影，不修改世界布局或节点身份。

## 实现证据

- `src/app.rs` 保存并更新 viewport，接受搜索结果时重置视口以重新定位 anchor。
- `src/tui/mod.rs` 实现世界布局、屏幕投影、裁剪及节点/背景拖拽手势。
- TUI 回归测试验证窄屏下屏外节点可分别通过节点拖拽和背景拖拽进入可见区域，同时世界布局和图结构保持不变。
