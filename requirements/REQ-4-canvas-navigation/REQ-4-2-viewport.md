# REQ-4-2：无限画布和平移

| 字段 | 值 |
| --- | --- |
| 父需求 | `REQ-4` |
| 状态 | `Implemented` |
| 优先级 | `P1` |
| 目标版本 | `0.1` |

## 需求

画布在逻辑上不受终端尺寸限制，节点使用世界坐标布局。用户可以拖拽背景或节点主体平移整体 viewport，以查看屏幕外节点；拖拽节点不表示单独重排该节点。

## 验收条件

- 平移只改变 viewport，不修改图结构或节点语义身份。
- 节点主体和画布空白区域都能发起平移；toggle 按钮不会误触发拖拽。
- 节点、连线和鼠标命中使用同一坐标变换。
- 节点只要与 viewport 相交就显示真实可见切片；完全离屏后才从当前帧消失。
- 裁剪边界不会被误画成新的组件边框，可见的节点主体或按钮仍可命中。
- 节点方框完全离屏时不自动删除其边；完整世界路径与 viewport 有交集的线段继续显示，路径也完全离屏时才不绘制。
- terminal resize 后重新裁剪显示，不丢失世界坐标。
- 多个图组件和 anchor 可以处于同一世界画布中。
- 选择或 toggle 引发世界布局重新锚定时，viewport 自动补偿，使交互目标的屏幕中心保持不变。

## 当前实现

App 保存有符号 viewport 偏移，拖拽事件按连续鼠标位置的增量做饱和平移。TUI 先为所有展开节点生成不依赖终端大小的世界布局，再以画布中心和 viewport 偏移投影；与可见区域存在交集的节点参与本帧方框渲染、命中和空间导航，完全离屏后才排除。节点先按完整尺寸渲染到局部 buffer，再复制真实相交切片，因此 viewport 边缘不会产生虚假的新边框。边路由使用全部世界节点的有符号投影，不依赖端点方框是否进入可见节点集合；每个正交线段先与 viewport 求交，再只栅格化交集 cell。selection 只对稳定世界布局做统一坐标平移；选择、toggle 或异步 hierarchy 完成前后，控制器计算目标节点中心的世界坐标差并累加反向 viewport 偏移。terminal resize 只重新投影，不修改世界布局或节点身份。

## 实现证据

- `src/app.rs` 保存并更新 viewport，接受搜索结果时重置视口以重新定位 anchor。
- `src/tui/mod.rs` 实现世界布局、屏幕投影、裁剪及节点/背景拖拽手势。
- TUI 回归测试验证窄屏下局部可见节点可分别通过节点拖拽和背景拖拽完整进入可见区域，同时世界布局和图结构保持不变；其他测试检查真实切片不会生成假边框、完全离屏后方框才消失，以及端点方框离屏后穿过 viewport 的边和目标方向仍然可见。
