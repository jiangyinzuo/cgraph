# REQ-5-4：新增或重定位图入口

| 字段 | 值 |
| --- | --- |
| 父需求 | `REQ-5` |
| 状态 | `Implemented` |
| 优先级 | `P1` |
| 目标版本 | `0.1` |

## 需求

接受搜索结果后，如果相同语义节点已经存在于关系图，应复用并选中该节点；否则创建新节点。搜索结果同时被固定为 anchor，使不可见或不连通的入口能够进入画布。

## 验收条件

- 判断语义相同时至少考虑 hierarchy kind 和源码位置，不能只比较名称。
- 已有语义节点被重新选择时不创建重复节点或重复 anchor。
- 新符号创建节点和 anchor，并保留精确 URI、行和列。
- 已存在但当前不可见的节点可以被固定为 anchor 并重新进入可见图。
- 多个 anchor 可以共享节点或边，也可以位于不同的不连通组件。

## 当前实现与差距

App 使用 RelationGraph 的全图 resolved identity 索引复用节点，并以有序、去重的 anchors 保存显式入口。接受结果会选择并固定已有节点或创建新节点，同时重置 viewport。

## 实现证据

- anchor 创建、复用、重定位与测试位于 `src/app.rs`。
- 图模型技术决策位于 `src/state/graph-model.md`。
