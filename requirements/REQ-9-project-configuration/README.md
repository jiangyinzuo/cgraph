# REQ-9：项目本地配置与符号过滤

| 字段 | 值 |
| --- | --- |
| 状态 | `Implemented` |
| 优先级 | `P1` |
| 目标版本 | `0.1` |
| 子需求 | 2 |

## 目标

每个项目可以版本控制自己的 cgraph 规则，选择项目使用的 LSP 命令，并隐藏 `into`、`is_some`、`Some` 等在关系图中噪声较高、但不适合作为所有项目全局默认值的符号。

## 子需求

| 子需求 | 状态 | 摘要 |
| --- | --- | --- |
| [REQ-9-1 配置与限定名过滤](REQ-9-1-filtering.md) | `Implemented` | `.cgraph.toml`、通配规则和语言限定名 |
| [REQ-9-2 在 TUI 中编辑并重载配置](REQ-9-2-edit-reload.md) | `Implemented` | `ec`、外部编辑器和图刷新 |

## 父需求验收

- 项目可以版本控制严格校验的 `.cgraph.toml`，并按语言惯用完整限定名过滤符号。
- 项目可以在 `[lsp]` 中指定 server `name`、`command`、`args` 和 `file_extensions`；省略后缀时使用 Rust、C/C++（含头文件）、Python 的内置 profile 默认值。
- 用户可以在 TUI 内打开项目配置，返回后无需重启即可应用新规则。
- 配置变更会刷新已经加载的图关系，显式 anchors 不被过滤器静默删除。

## 当前实现

启动加载、通配匹配、限定方法名和查询过滤已经交付。`ec` 会安全挂起 TUI、使用 `$EDITER`（或 `$EDITOR`）打开项目配置、严格重载，并刷新全部已加载的可达图分支；错误保留上一份有效配置和现有图。
