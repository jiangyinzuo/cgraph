# REQ-2-3：底部状态栏布局

| 字段 | 值 |
| --- | --- |
| 父需求 | `REQ-2` |
| 状态 | `Implemented` |
| 优先级 | `P0` |
| 目标版本 | `0.1` |

## 需求

TUI 最底部一栏应始终同时显示快捷键提示和分析后端状态。快捷键位于左侧，后端、阶段、可选百分比与状态详情紧随其后。普通操作信息与错误使用独立的倒数第二行，不能替换快捷键提示。

## 验收条件

- 正常尺寸终端在同一最底行显示快捷键、后端、阶段、可选百分比和消息。
- 状态含义不只依赖颜色。
- 快捷键和状态摘要在同一行连续排列，不为两者预留固定比例的空白区域。
- 窄终端可以从整行自然截断文本，但仍保持单行 footer 和主交互。
- 信息和错误默认显示在倒数第二行，错误带有 `ERROR:` 前缀；所有消息进入 `g<` 历史。
- `g<` pager 从倒数第二行向上展开，最底行快捷键与后端状态保持可见。

## 实现证据

当前底部布局由一行消息摘要和一行固定 footer 组成。footer 中快捷键后紧接后端状态摘要并统一按终端宽度裁剪；测试通过虚拟终端断言错误位于倒数第二行、快捷键不变，以及 `g<` 展开后 footer 仍可见。渲染位于 `src/tui/mod.rs`；`src/tui/messages.rs` 使用 Ratatui 原生组件实现 pager，并在打开期间让终端接管鼠标文本选择。
