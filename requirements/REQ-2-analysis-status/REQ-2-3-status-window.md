# REQ-2-3：底部状态栏布局

| 字段 | 值 |
| --- | --- |
| 父需求 | `REQ-2` |
| 状态 | `Implemented` |
| 优先级 | `P0` |
| 目标版本 | `0.1` |

## 需求

TUI 最底部一栏应同时显示快捷键提示和分析后端状态。快捷键位于左侧，后端、阶段、可选百分比与消息位于右侧；状态不得另行覆盖画布、搜索弹窗或退出操作。

## 验收条件

- 正常尺寸终端在同一最底行显示快捷键、后端、阶段、可选百分比和消息。
- 状态含义不只依赖颜色。
- 左右区域有稳定边界，状态消息不能覆盖快捷键区域或画布。
- 窄终端可以截断各自区域的文本，但仍保持单行 footer 和主交互。

## 实现证据

当前 footer 高度固定为一行，左侧快捷键与右侧状态约按 3:2 分配；测试通过虚拟终端断言二者只出现在同一条最底行。渲染位于 `src/tui/mod.rs`。
