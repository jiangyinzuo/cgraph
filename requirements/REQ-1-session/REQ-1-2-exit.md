# REQ-1-2：退出与终端恢复

| 字段 | 值 |
| --- | --- |
| 父需求 | `REQ-1` |
| 状态 | `Implemented` |
| 优先级 | `P0` |
| 目标版本 | `0.1` |

## 需求

Canvas 模式下按 `q` 或 `Esc` 应退出 ctree。退出路径必须尝试恢复终端，并按协议关闭本进程拥有的语言服务器。

## 验收条件

- `q` 和 `Esc` 都会结束正常事件循环。
- 正常退出恢复 raw mode、备用屏幕、鼠标捕获和光标。
- LSP 会话收到 `shutdown` 与 `exit`；超时后子进程被回收。

## 当前边界

进程被操作系统强制终止时无法保证发送终端恢复序列；用户排障方式记录在 `docs/troubleshooting.md`。
