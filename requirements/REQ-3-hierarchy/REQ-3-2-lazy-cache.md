# REQ-3-2：懒加载与缓存

| 字段 | 值 |

## 需求

LSP 或 Tree-sitter 查询采用懒加载：某方向首次展开时才请求一层孩子。成功结果写入缓存，收起不清除数据。

## 验收条件

- 未展开节点不主动执行 hierarchy 子节点查询。
- 再次展开成功缓存的分支不重复请求。
- 多层展开后，祖先收起再展开时恢复此前的深层展开状态。
- 左、右单层结果按全局语义身份复用节点；每个分支的 neighbor 顺序保持 provider 首次出现顺序，同一规范边可记录多个查询方向来源。
- 错误和取消结果不写入永久成功缓存。
- 显式刷新可以绕过当前层缓存。

## 当前实现与差距

LSP 首次展开、一层结果缓存、全图语义节点去重、深层展开状态保留、错误重试和 request-id 过期结果拒绝已经实现。成功空结果会进入 `Loaded`，错误不会写入成功缓存。显式刷新由 `REQ-3-4` 管理，尚未接入，因此本需求保持 `Partial`；Tree-sitter hierarchy 也仍是后续能力。
