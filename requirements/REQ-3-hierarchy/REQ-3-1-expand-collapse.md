# REQ-3-1：双向展开与收起

| 字段 | 值 |
| --- | --- |
| 父需求 | `REQ-3` |
| 状态 | `Implemented` |
| 优先级 | `P1` |
| 目标版本 | `0.1` |

## 需求

每个节点左右两侧都有独立展开按钮。左侧展示调用它的函数或父类型，右侧展示它调用的函数或子类型。展开后的节点可以继续向任一方向展开。

鼠标点击节点左侧或右侧按钮切换对应分支；键盘 `tl` 只切换当前节点左侧 incoming/parent 分支，`tr` 只切换右侧 outgoing/child 分支。不存在同时展开两侧的单键 `t` 行为。

## 验收条件

- 左右分支可以独立展开和收起。
- 收起一侧不改变另一侧状态。
- 子节点可以递归执行同样操作。
- 不支持某方向时显示明确状态，而不是永久 Loading。
- 鼠标或键盘 toggle 不改变被操作节点在 viewport 中的中心位置；异步 hierarchy 结果到达并改变布局或节点宽度时仍保持该锚点。

## 当前实现与差距

独立左右 toggle、递归可见性、统一鼠标命中和首次 LSP hierarchy 加载已经实现。`[+]`、`[~]`、`[-]`、`·`、`[!]` 分别表示可加载/展开、加载中、已展开、成功空结果和失败；失败不会停留在永久 Loading，并可通过同一操作重试。toggle 立即状态变化和随后到达的异步结果都以操作节点中心为 viewport 锚点，展开、收起、名称解析和列宽变化不会把该节点移走。
